# **App Name**: FitZen

## Core Features:

- User Authentication & Profiles: Secure sign-up/login using email, phone, or Google. Customizable user profiles with age, height, weight, gender, fitness goal, and activity level selection.
- Personalized Workout Plans: AI-powered workout recommendations based on fitness goals, available equipment (home/gym), and time duration (15-60 min). Generative AI will use a tool to personalize workout plan based on user progress.
- Exercise Library: Browse exercises by category (Chest, Back, Legs, Arms, Abs, Cardio, Yoga, Stretching) with details including name, description, steps, GIF/video demo, target muscles, and difficulty level.
- Diet & Nutrition Planner: Personalized diet plans and daily calorie calculator with macronutrient breakdown (Protein, Carbs, Fats), Veg/Non-veg/Vegan options, and meal reminders.
- Progress Tracking: Track weight, body measurements, workout completion history, and calories burned vs consumed. Visualize progress with charts & graphs.
- BMI, BMR & Calorie Calculator: Calculate BMI, BMR, maintenance calories, and goal-based calorie deficit/surplus to help users manage their weight and nutrition effectively.
- Reminders & Notifications: Set workout, meal, and water intake reminders, plus inactivity alerts to encourage consistent engagement and healthy habits.

## Style Guidelines:

- Primary color: A vibrant shade of blue (#29ABE2), evoking a sense of trustworthiness, vitality, and technological savvy, which resonates with health and fitness.
- Background color: A light, desaturated tint of blue (#E5F6FD) will maintain harmony while providing a clean backdrop.
- Accent color: A saturated green (#90EE90) that will emphasize progress and good health.
- Body and headline font: 'Inter' sans-serif for a modern, machined and neutral aesthetic.
- Use clear, modern icons representing different exercises, food groups, and tracking metrics.
- A clean, intuitive layout with clear information hierarchy and easy navigation is key for user engagement.
- Subtle, engaging animations will confirm successful goal achievement or data entry to improve user experience.
